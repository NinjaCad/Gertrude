## 🃏 *Gertrude’s Blackjack*

### 🎮 Overview

*Gertrude’s Blackjack* is a command-line blackjack game where players compete against a dealer with personality. The game includes multiple betting options, player actions, and dynamic dialogue to make each round feel interactive.

---

## 🎮 How to Run the Game

1. Navigate to the `src` directory:

   ```bash
   cd /app/src
   ```

2. Start the game:

   ```bash
   python -m cardgames.Games
   ```

---

## 🕹️ How to Play

* Run the game from the terminal
* Enter number of players and starting money
* Place bets each round
* Choose actions:

  * **Hit**
  * **Stand**
  * **Double Down**
  * **Split**
* Try to beat the dealer without going over 21

---

## ⚙️ Features

* **Full blackjack system** (hit, stand, split, double down)
* **Multiple side bets** (insurance, perfect pairs, 21+3)
* **Dynamic dealer (Gertrude)** with dialogue and reactions
* **Multi-player support**
* **Money and betting system**
* **Round-based game loop with replay option**
